# T-DuoBar

Наш форк [DuoBar от Mikeli7666](https://github.com/Mikeli7666/DuoBar): компактный индикатор в строке меню macOS с расширенной информацией о батарее, сети и аудиоустройствах.

[English](README.md) · [Разработка и локальная установка](DEVELOPMENT.md)

## Установка и обновление через Homebrew

```sh
brew install --cask squazaryu/tap/t-duobar
brew update
brew upgrade --cask squazaryu/tap/t-duobar
```

Перед первой установкой через Homebrew завершите установленный вручную DuoBar и сохраните `/Applications/DuoBar.app`. `--adopt` подходит только для идентичной копии; не используйте `--force`, чтобы потерять старую установку.

С 1.6.0 приложение проверяет опубликованную версию Homebrew раз в неделю, пока запущено, и догоняет пропущенную проверку после запуска или пробуждения Mac. О новой версии приходит одно уведомление, если разрешено macOS. Кнопка **«Установить через Homebrew»** открывает Terminal с подготовленным скриптом: он обновляет приложение и запускает его снова. Установка происходит только после нажатия. Если Homebrew отсутствует, выводится инструкция; менеджер пакетов автоматически не устанавливается.

В «Настройки → Обновления приложения» есть переключатель недельных проверок, ручная проверка, установка, release notes и команда обновления. При закрытом приложении проверки не идут. После сетевой ошибки повтор выполняется через шесть часов.

С версии 1.6.1 настройки всегда показывают установленную версию и номер сборки. После каждой ручной проверки появляется окно: установленная и доступная версии с кнопкой установки, подтверждение актуальности установленной версии или ошибка соединения. Еженедельное уведомление об обновлении также содержит установленную и доступную версии. Для окон ручной проверки разрешение на системные уведомления не требуется.

## Сборка и установка

Нужны macOS 13+ и полный Xcode. Сборка и тесты проверены на Apple Silicon; все версии macOS и аксессуары физически не проверялись.

```sh
git clone https://github.com/squazaryu/T-DuoBar.git
cd T-DuoBar
./script/build_and_run.sh --verify
```

Скрипт собирает Release, проверяет локальную подпись, устанавливает `/Applications/DuoBar.app` и проверяет путь запущенного процесса. Предыдущая копия сохраняется в `~/Library/Application Support/T-DuoBar/Backups/`.

**Сборки этого форка с Developer ID и notarization пока нет.** Экспериментальный DMG и локальная сборка имеют ad-hoc подпись. Имя приложения и bundle identifier сохранены: используются прежние настройки, установленный DuoBar заменяется, одновременный запуск форка и оригинала не предусмотрен.

## Проверки и ограничения

Для реализации 1.6.1 прошли 273 теста; шесть аппаратных проверок пропущены. Проверка на конкретных устройствах остаётся отдельным этапом.

- Оценка времени берётся из macOS и может быть недоступна.
- Показания аксессуаров зависят от системного отчёта Bluetooth. Чтение выполняется локально, пока открыт соответствующий блок меню.
- Достоверный публичный источник лимита заряда пока не найден: поле отображает «Недоступно». Лимит не угадывается по заряду 80% или приостановленной зарядке.
- Мощность адаптера — сообщаемый номинал, а не измерение текущей мощности зарядки.
- Данные Wi-Fi могут быть скрыты macOS; некоторые аудиоустройства не поддерживают программное управление громкостью.
- Уведомление появляется при пересечении порога, а не сразу при запуске с низким зарядом.

Нет аналитики и передачи системных показаний. Проверка обновлений выполняет HTTPS-запрос к файлу версии нашего Homebrew tap; данные батареи, сети и устройств не передаются. Выбор микрофона меняет устройство ввода Core Audio; приложение не записывает звук.
